Solution Title
SafeCheck AI — Real-Time Scam Number & Suspicious Message Checker

The Problem
Every day, customers receive convincing texts, calls, and emails from scammers impersonating banks, couriers, or official support teams. Because these messages create artificial urgency and mimic trusted brands, users often panic, click malicious links, or call back fraudulent numbers before realizing it is a scam.   

Our Solution
SafeCheck AI is a fast, zero-friction public web tool that empowers customers to verify any suspicious phone number or message before taking action. Instead of guessing whether a support contact is genuine, users can paste a phone number, a suspicious message, or both into a clean two-step checker to receive an instant risk breakdown and safe verification steps.   

Key Features
Two-Step Contact & Message Lookup: Customers can check a standalone phone number in Step 1, analyze a text/email in Step 2, or cross-check both together for brand-to-number mismatches.

Real-World Number Intelligence: Automatically detects the visitor's local region and evaluates international ITU E.164 country prefixes, cross-border spoofing indicators (such as overseas prefixes impersonating local support), premium-rate/toll-free lines, and unverified sender IDs.

Clear Visual Verdict & Numbered Red Flags: Displays an at-a-glance Number Intelligence Bar alongside a clear Suspicious status badge, listing numbered warning signs (such as urgency tactics, phishing domains, and credential requests) so users understand why a message is risky.   

Actionable Safety Checklist: Provides numbered, step-by-step instructions on how to safely verify the claim through official channels without engaging the scammer.   

Production-Ready Public Web App: Built as a lightweight, client-side web application (HTML, CSS, and modular JavaScript engine) ready for instant public deployment with zero backend latency.

How It Was Built
Built in under 20 minutes using Antigravity 2.0, iteratively refining the interface from a simple alert concept into a clean, public-facing security utility with client-side E.164 prefix analysis and domain verification.
