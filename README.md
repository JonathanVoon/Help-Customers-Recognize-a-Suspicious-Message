# SafeCheck AI — Public Customer Protection Website

Production-ready web application for checking suspicious contact phone numbers, sender IDs, and SMS/WhatsApp/email messages.

## Public Deployment Options (Free & Instant)

### Option 1: Netlify Drop (Fastest — No Account CLI Setup Needed, 15 Seconds)
1. Go to https://app.netlify.com/drop
2. Drag and drop the entire `suspicious-message-checker` folder onto the page.
3. Netlify will immediately give you a live public `https://...netlify.app` URL that anyone can visit.

### Option 2: GitHub Pages / Vercel / Cloudflare Pages
1. Push this folder to a GitHub repository.
2. Enable **GitHub Pages** (Settings → Pages → Deploy from branch `main`), or import the repo into **Vercel** (`vercel.json` is pre-configured) or **Netlify** (`netlify.toml` is pre-configured).
